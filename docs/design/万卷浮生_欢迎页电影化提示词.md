# 万卷浮生 · 电影化欢迎页实施提示词

在现有 `frontend/` 项目中设计并实现“万卷浮生”的全屏电影化欢迎页。它是一个东方志怪典籍互动游戏入口，不是 SaaS 营销页，也不是只服务于仙侠题材的通用模板。

## 项目语境

“万卷浮生”以中国古典名著为内容入口，玩家可以进入典籍、通过 AI 推进分支剧情、唤醒和养成书中角色、收集法宝，并让不同作品中的角色进入演武场对战。

欢迎页应传达：

> 纸上有字，字里众生。移动灵识，照见浮生。

核心体验只有一个：玩家移动鼠标或触摸画面时，暗色基础世界中会被柔和地揭示出同一场景的隐藏信息，包括文字脉络、角色残影、法宝印记与剧情分支。

## 现有技术与修改边界

- 使用项目已有 React 19、TypeScript、Vite 6、Tailwind CSS 4、React Router、Zustand、GSAP 和 `lucide-react`。
- 不安装新依赖，不重建应用脚手架，不修改公共路由、Store 数据结构或其他页面。
- 主要修改 `src/views/WelcomeView.tsx` 和 `src/ui-v2.css` 中的 Welcome 专属样式。
- 复用 `tokens.css` 的墨夜、绢纸、鎏金、朱砂、青玉变量和现有中文字体栈；不要添加 Google Fonts 或 Tailwind 3 指令。
- 保留现有 GSAP 墨迹扩散转场和路由进入逻辑。

## 本地背景素材

使用项目本地资源：

```ts
const BASE_WORLD_IMAGE = '/welcome/welcome-world-base.png'
const REVEAL_WORLD_IMAGE = '/welcome/welcome-world-reveal.png'
```

文件保存于 `frontend/public/welcome/`，避免被项目现有 `/images` 开发代理接管。

两张图具有相同镜头、山体、藏经楼、卷轴、云雾和水面构图：

- 基础层是近黑、石墨灰和低饱和蓝灰的墨夜山河。
- 揭示层只增加克制的金玉文字脉络、角色残影、法宝印记和剧情分支。
- 图片本身不包含文字、Logo、卡片或 UI。

## 页面结构与文案

使用 `100dvh` 的全屏场景，界面层级依次为：基础背景、电影化暗角、揭示背景、纸张颗粒、标题、底部信息、导航与交互提示。

顶部导航：

- 左侧品牌：“万卷浮生”，配合简洁的书卷/山形 SVG 标记。
- 桌面中部入口：“书库”“角色”“法宝”“浮生录”“演武场”，对应 `/library`、`/characters`、`/items`、`/story`、`/battle`。
- 右侧按钮：“AI 设置”，进入 `/settings`。
- 移动端隐藏桌面导航，提供可关闭的紧凑菜单；支持 Escape 关闭，不实现大型抽屉。

主标题位于上方视觉安全区：

```text
AI 互动典籍 · 群英跨卷相逢
万卷浮生
一页入世，一念改命
```

底部左侧仅在平板和桌面显示：

```text
读一部书，唤醒其中人物；
借 AI 改写支线，让跨越千年的群英于一卷相逢。
```

角色数据加载成功且数量大于零时显示真实的“X 位角色已入卷”；否则显示“典籍世界待启”。不要使用虚构固定数量。

底部右侧：

```text
从典籍入卷，在剧情中养成角色，收集法宝，最终走入演武场。
[开启书卷 ↗]
```

主按钮进入 `/library`。当前项目没有可靠的持久化存档状态，不显示“继续游历”，也不伪造“世界记忆已开启”等系统状态。

桌面下方中央显示低对比度提示：

```text
移动灵识 · 照见浮生
```

## “照见浮生”揭示交互

- 不使用 Canvas `toDataURL()`，避免每帧编码和 React 重渲染。
- 揭示层使用 CSS `radial-gradient` 作为 `mask-image` 和 `-webkit-mask-image`。
- 通过 `requestAnimationFrame` 平滑更新揭示元素的 CSS 自定义属性。
- 鼠标目标位置与平滑位置分别保存在 `useRef` 中，插值系数约为 `0.1`。
- 桌面揭示半径约 `260px`，触屏约 `190px`。
- 首次指针或触摸交互前完全隐藏揭示层；指针离开场景时柔和淡出。
- 统一使用 Pointer Events 处理鼠标与触控，卸载时移除监听并取消 RAF。
- 不渲染可见光圈、边框、手电筒 UI、鼠标跟随 DOM 粒子或持续漂浮特效。
- 揭示层属于装饰信息，设置 `aria-hidden="true"`，不能影响按钮点击与键盘导航。

## 视觉语言

- 场景第一、UI 第二；神秘感优先于功能说明。
- 背景近黑，正文使用温暖绢纸白，主强调使用克制鎏金，次强调使用低饱和青玉。
- 导航直接浮在场景上，可用极轻的黑色半透明衬底和细边线，不使用白色玻璃卡片。
- UI 保持轻量，中心和下方中部尽量留给场景。
- 标题使用现有衬线中文字体，字重正常或偏轻，不使用渐变文字。
- 颗粒与墨扩散纹理接近不可见，只用于消除数字画面的洁净感。
- 入场动画只运行一次，缓慢、柔和、有目的；保留 `prefers-reduced-motion` 支持。

避免：霓虹青紫、赛博朋克、通用 MMO HUD、卡片墙、亮橙色按钮、红金宫廷庆典、过度玻璃拟态、巨大 CTA、中文装饰边框堆叠、通用 AI 星光、所有元素持续漂浮。

## 响应式与可访问性

- 桌面：完整导航、底部双栏文案、中央交互提示和 260px 揭示半径。
- 平板：压缩侧边间距，保留底部左侧说明，避免标题与导航冲突。
- 移动端：隐藏桌面导航和底部左侧说明；显示紧凑菜单；底部 CTA 保持在安全区内；揭示半径约 190px；关键背景主体应适配中心裁切。
- 所有交互目标至少 44×44px，具有清晰 `focus-visible` 状态。
- `prefers-reduced-motion` 下取消入场位移与缩放，揭示位置直接响应输入或使用极短过渡。

## 验收标准

- 初始状态只显示基础世界，揭示层不会漏出。
- 鼠标与触摸只在柔和圆形遮罩内显示隐藏世界，且运动平滑。
- 1440×900、1024×768、390×844 下无横向滚动、文字碰撞或不可点击区域。
- 移动菜单可打开、关闭、按 Escape 关闭并正确导航。
- “开启书卷”和顶部入口进入现有正确路由。
- `npm run build` 与 `npm run lint` 通过。
